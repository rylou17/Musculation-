Les données sont stockées localement dans Safari sur cet iPhone. Elles ne sont pas synchronisées automatiquement entre appareils. Exporte régulièrement une sauvegarde JSON dans Fichiers ou iCloud Drive. L'import remplace les données présentes sur cet appareil.
